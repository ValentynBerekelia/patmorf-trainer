# PathoQuiz

Інтерактивний тренажер з патоморфології. Усі дані — зображення, назви, описи —
витягнуті з файлу **«Патоморфологія препарати.pdf»** (41 сторінка, макроскопічні
препарати до Підсумкового модуля №1). Нічого не вигадано: кожен опис на сайті
дослівно відповідає тексту PDF.

- **116 препаратів**, **120 зображень** (4 препарати мають по два знімки)
- **108** препаратів мають екзаменаційний номер з PDF (`№ 2`, `№ 22/27`, `№ 940/28`…), **8** — без номера
- **97** унікальних діагнозів

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Інші команди:

```bash
npm run build      # збірка в dist/
npm run preview    # перегляд зібраної версії
npm run typecheck  # перевірка типів
node scripts/verify.mjs   # перевірка цілісності даних і логіки тренувань
```

## Режими

| Режим | Маршрут | Що робить |
|---|---|---|
| Вгадай препарат | `/#/quiz` | 12 препаратів за сесію, 4 варіанти, миттєвий розбір і опис із PDF |
| Повторення | `/#/cards` | Колода з 20 карток, 3D-перевертання, «Знаю» / «Потрібно повторити» |
| Складний іспит | `/#/exam` | 20 питань у випадковому порядку, без підказок; у кінці — результат і розбір помилок |
| Слабкі місця | `/#/weak` | Тільки препарати з помилками, відсортовані за їх кількістю |
| Каталог | `/#/catalog` | Усі 116 препаратів, пошук за назвою/органом/номером, фільтр за категорією |
| Статистика | `/#/stats` | Успішність, покриття бази за категоріями, історія останніх 20 сесій |

Усередині однієї сесії препарат ніколи не повторюється. Варіанти відповідей
щоразу перемішуються, правильний завжди присутній, відволікачі беруться
переважно з тієї ж категорії.

### Як працює черговість

Препарати, на яких ви помиляєтесь або які позначили «Потрібно повторити»,
отримують більшу вагу й частіше випадають у наступних сесіях
([`src/lib/srs.ts`](src/lib/srs.ts)). Вага також росте для препаратів, яких ви
давно не бачили, і для тих, що ще жодного разу не траплялися.

## Архітектура

```
src/
  data/
    preparations.json    ← уся база (єдине джерело правди)
    preparations.ts      ← типізований доступ, URL зображень, підписи
  types.ts               ← типи Preparation, ProgressState тощо
  lib/
    quiz.ts              ← генерація питань і варіантів відповіді
    random.ts            ← перемішування та зважена вибірка без повторів
    srs.ts               ← ваги препаратів, слабкі місця
    storage.ts           ← читання/запис LocalStorage з валідацією
  context/
    ProgressContext.tsx  ← стан прогресу на весь застосунок
  components/            ← Layout, PrepImage, PrepDetails, QuizRunner, StatCard
  pages/                 ← Home, Quiz, Flashcards, Exam, Weak, Catalog, Detail, Stats
public/preparations/     ← зображення, витягнуті з PDF
tools/extract_from_pdf.py← скрипт, що згенерував базу з PDF
scripts/verify.mjs       ← перевірки даних і логіки
```

Дані повністю відокремлені від UI: жоден компонент не містить назв препаратів.

## Як додати нові препарати

**Варіант 1 — вручну.** Покладіть зображення в `public/preparations/` і додайте
запис у масив `preparations` файлу `src/data/preparations.json`:

```json
{
  "id": "p117",
  "index": 117,
  "number": "123",
  "organ": "Нирка",
  "diagnosis": "Коротка назва діагнозу",
  "category": "circulation",
  "pdfPage": 42,
  "images": [{ "src": "preparations/prep-117.jpeg", "width": 400, "height": 520 }],
  "description": {
    "organ": "…", "localization": "…", "shape": "…", "size": "…", "structure": "…"
  },
  "dx": { "main": "…", "visible": "…", "probable": "…" },
  "needsReview": null
}
```

Допустимі `category`: `tumors`, `inflammation`, `circulation`, `dystrophy`,
`necrosis`, `adaptation`, `other`. Після правки запустіть `node scripts/verify.mjs`.

**Варіант 2 — перегенерувати з PDF:**

```bash
pip install pymupdf
python tools/extract_from_pdf.py "C:/шлях/до/Патоморфологія препарати.pdf"
```

Скрипт заново витягне зображення та описи. Короткі назви діагнозів лежать
окремо в `tools/diagnoses_map.py` — вони виписані з пункту 6.А кожного
препарату.

## Зберігання прогресу

Ключ LocalStorage: `pathoquiz:progress:v1`. Зберігаються кількість правильних і
хибних відповідей по кожному препарату, позначки «Знаю» / «Потрібно повторити»,
час останнього показу та історія останніх 20 сесій. Пошкоджені дані не ламають
застосунок — він відкотиться до чистого прогресу. Скинути можна на сторінці
«Статистика».

## Місця, що потребують ручної перевірки

Три препарати мають описки в самому PDF — у застосунку вони позначені жовтою
плашкою на детальній сторінці:

| Препарат | Проблема |
|---|---|
| №15, селезінка | «лімфогенного **етастазування**» — пропущена літера |
| №647, селезінка | у п.6.А написано «ціанотична індурація **нирки**», хоча орган у п.1 — селезінка |
| №658, селезінка | «**аа**мілоїдоз» — подвоєна літера |
